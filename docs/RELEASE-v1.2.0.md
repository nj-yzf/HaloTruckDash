# HaloTruckDash 1.2.0

新增本地反馈包和GitHub问题反馈入口，补齐日志与运行状态记录。

- 在“设备与诊断…”点击“导出反馈包”，自动打开保存文件夹；再点击“反馈问题…”填写模板并手动附上ZIP。
- 反馈导出独立于音响同步线程，可收集当前操作耗时、连接与失败计数、近期日志、USB/遥测快照和插件只读校验结果。
- 自动遮蔽常见路径及已知设备标识，排除配置、保存布局和原屏幕恢复内容；不自动上传文件。
- 日志每份约2MB，保留三份轮换备份，补齐状态变化与异常记录。修复后台初始化失败后退出等待无法完成的问题。
- 增加命令行`--feedback`，便于界面打不开时导出。

下载win-x64.zip解压运行。升级前关闭旧版，将旧版data目录复制到新版旁可保留设置和布局。正式版不含在线更新。

73项单元测试、五组原生窗口检查和隔离EXE检查通过；提供SHA256SUMS.txt。详细反馈说明见随包docs/SUPPORT.md。
