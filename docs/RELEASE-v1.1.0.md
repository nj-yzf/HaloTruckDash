# HaloTruckDash 1.1.0

新增“设备与诊断…”面板，让其他Halo PixelBar硬件版本能够先检查基础协议，再尝试同步。

- 保留A160/A106的原有识别流程；候选列表增加其他PID及相关HID接口，无需先修改代码中的PID列表。
- 未知设备不会自动连接。停止同步后，可选中符合条件的控制接口，点击“验证并选用”；验证只查询屏幕状态和原文字，不修改显示。
- 验证记录绑定具体设备、接口及USB修订信息，未知版本每次连接仍检查协议；多台音响可明确选择一台。
- 屏幕恢复记录增加设备校验，避免换设备后误用原设置。
- 支持界面导出诊断；包含未知候选接口信息，不导出USB序列号、设备路径及本地设备标识哈希。

下载`HaloTruckDash-v1.1.0-win-x64.zip`，解压运行。升级前关闭旧版，将旧版`data`目录复制到新版旁可保留设置和布局。正式版仍不含在线更新。

支持Windows 10/11 x64、欧卡2及美卡。A160已有实机验证，A106有公开协议依据；其他硬件版本通过基础查询后仍需用户观察实际同步和恢复效果，不代表所有型号均已适配。

64项单元测试、五组原生窗口检查及隔离EXE检查通过。提供SHA256SUMS.txt校验下载文件。
