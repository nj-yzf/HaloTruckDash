# HaloTruckDash 1.0.0

首个正式版，以0.4.1的仪表功能为基础整理。软件名称统一为HaloTruckDash，新增原创程序图标；0.5.0在线更新功能保留在独立的`online-updates`分支，正式版不含在线更新。

- 支持欧卡2与美卡，车速、挡位、限速、转向灯、油量和时间等仪表信息同步到Halo PixelBar。
- 两套默认布局及30格自由布局编辑器，支持框选整体移动、多方案保存和JSON分享。
- 自动检测Steam游戏库，支持不同盘符、中文与空格路径；安装目录不可写时自动使用用户数据目录。
- 补齐EXE、窗口和任务栏图标以及Windows文件版本信息。
- 原创代码与图标采用MIT许可，第三方组件许可随包提供。

下载`HaloTruckDash-v1.0.0-win-x64.zip`，解压运行，无需安装Python。升级前关闭旧版，将旧版data目录复制到新版旁可保留配置。

支持Windows 10/11 x64；本项目已实测A160、ETS2与ATS，用户已确认与SimHub协同工作正常。A106有协议适配依据，尚待本项目实机验证；其他型号/品牌音响未适配。游戏遥测插件需要Visual C++ v14 x64运行库，缺少时可安装[微软官方运行库](https://aka.ms/vc14/vc_redist.x64.exe)。

49项单元测试、四组原生窗口检查及隔离EXE检查通过。SHA256SUMS.txt用于校验下载文件。
