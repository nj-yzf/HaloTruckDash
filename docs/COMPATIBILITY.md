# 兼容性说明

| 项目 | 范围与验证情况 |
| --- | --- |
| 正式发布程序 | Windows 10/11 x64；包含Python、Tcl/Tk及HID运行组件，无需安装Python |
| Windows ARM64 | 没有原生ARM64发布包；x64模拟运行尚未实测 |
| Windows 7/8、32位Windows、macOS、Linux | 不支持当前Windows x64发布包 |
| 游戏 | ETS2和ATS的64位版本，用户已确认两者真实驾驶和音响同步正常 |
| 遥测插件 | RenCloud V.1.12.1，共享内存修订12；依赖Visual C++ v14 x64运行库 |
| SimHub | 用户已确认与当前测试组合协同工作正常；不同插件版本仍需核对 |

程序检测Steam注册表位置及libraryfolders.vdf中的其他游戏库，支持不同盘符、中文和空格路径；非Steam安装可手动选择。程序目录不可写时，设置回退到用户LOCALAPPDATA目录。单元、原生窗口及便携EXE检查不等同于在所有电脑型号上实测。

SCS插件导入MSVCP140.dll、VCRUNTIME140.dll及Windows Universal CRT。如果插件未载入，可安装[微软官方Visual C++ v14 x64运行库](https://aka.ms/vc14/vc_redist.x64.exe)。程序不会自动安装运行库或更换其他仪表的软件插件。

## 音响

| USB型号 | 适配状态 |
| --- | --- |
| VID 2D99 / PID A160 | 本项目实机验证；32字符布局、同步与恢复已经用户测试 |
| VID 2D99 / PID A106 | 有公开Halo PixelBar协议依据，并已加入筛选；尚待本项目实机验证 |
| 其他Halo PixelBar硬件版本 | 发现候选接口后需手动通过基础协议验证；尚无本项目实机验证，不保证显示效果 |
| 其他型号/品牌音响 | 不属于本项目适配范围 |

已知设备除VID/PID外，还校验HID接口4、usage page FF14及usage 1；系统能提供产品名称时还校验Halo/PixelBar名称。产品字符串缺失时仍可识别已知硬件ID。发送设置前查询并检查响应格式。每次仅向一台音响同步，多台连接时可在“设备与诊断…”中验证并选用其中一台；已选设备拔出后不会自动改选另一台。

同型号的另一台音响预计可使用相同协议，但不同固件可能改变读回格式或可显示空间；A106及其他实体设备仍需验证。USB线、转接器和扩展坞需能正确枚举数据接口。

### 未知硬件版本和诊断

PID由设备厂商指定，不是每台电脑分配的编号，也不能单独证明协议兼容。程序的候选列表不再限于A160/A106：会枚举VID 2D99的相关接口，以及名称同时含PixelBar和Halo（或花再）的设备。枚举本身不打开设备，也不发送HID报告。无法提供这些识别信息的设备仍可能不出现在列表中，不能保证覆盖所有硬件版本。

1. 打开“设备与诊断…”并刷新，选中“待验证”接口。
2. 停止本程序及其他程序对音响屏幕的同步，点击“验证并选用”。
3. 基础验证通过后，开始同步并观察文字、颜色及停止后的恢复效果。

未知设备只有名称或已知硬件标识符合条件，且usage page为FF14、usage为1时才提供验证；接口编号可以不同。信息不足或其他用途的接口标为“仅供诊断”，不发送查询。验证只查询屏幕状态和现有文字（EE/E7），检查响应校验、格式及原文字可恢复范围，不修改屏幕。通过这些查询只说明基础协议吻合，不等于已验证所有显示功能。

验证结果保存在本地`data/validated-devices.json`，绑定设备标识、接口和USB修订号；不会将一个PID的所有设备一起放行。没有序列号时以设备路径区分，换USB接口可能需要重新验证；USB修订号变化也需要重验。未知版本每次连接仍会重新查询协议。该本地记录不是可跨电脑分享的适配声明。

屏幕恢复记录也绑定设备，避免把另一台音响的原设置套用到当前设备。旧版未绑定的记录仅允许已知设备承接；若提示记录属于其他设备，应连接原音响完成恢复，或先备份旧记录再处理。

“设备与诊断…”的导出按钮和命令`HaloTruckDash.exe --diagnose`均包含候选接口的VID/PID、名称、usage及USB修订信息，不发送HID查询或设置，也不导出序列号、设备路径或本地设备标识哈希。反馈问题时可提供`diagnostics.json`，无需上传整个data目录。

## 与其他程序共存

本程序只读Local\SCSTelemetry，不监听遥测网络端口，不改变游戏输入。多个读取程序可共享匹配插件；不同插件若覆盖同名DLL或同一共享内存仍可能冲突。安装器拒绝覆盖不同内容的scs-telemetry.dll，保留其他DLL。音响屏幕仅由一个程序控制。

SimHub的用户共存实测反馈已记录；[其官方排障说明](https://github.com/SHWotever/SimHub/wiki/SimHub-Basics----Games-config-and-troubleshooting#ets2--ats)仍提示部分遥测插件分支存在冲突，因此此结果不代表所有历史和未来版本组合都已验证。
