# Halo Truck Dash · 欧卡/美卡点阵仪表

适用于 Windows 10/11 64位，通过 USB 将欧洲卡车模拟2（ETS2）或美国卡车模拟（ATS）的仪表信息显示到花再 Halo PixelBar。解压后运行 `HaloTruckDash.exe`，无需安装 Python。

## 开始使用

1. 使用可传输数据的 USB 线连接音响；仅连接蓝牙不能控制点阵屏。
2. 首次使用，在主界面下方选择对应游戏及游戏根目录，点击“安装遥测插件”。两款游戏需分别安装；已有相同插件时无需重装。
3. 完全重启对应游戏，接受 SDK 提示并进入驾驶。
4. 选择显示方案、颜色、速度单位及挡位模式，点击“开始同步到音响”。未运行游戏时可勾选“模拟演示数据”预览。

停止同步或正常退出会恢复原屏幕。异常退出后可重新打开程序，点击“恢复原屏幕”；USB 中断会自动重连。同步时请关闭其他程序对音响屏幕的控制。

## 布局与显示

```text
默认布局1：< A12  080/090km/h  09:45  67% >
默认布局2：< A12  L090 080km/h  09:45 67% >
```

两端为转向灯，中间30格可自定义。自动挡显示 A/N/R，手动挡显示数字；挡位识别不符时可强制选择。速度单位可选 km/h 或 mph，统一转换车速、限速和巡航目标；**自定义布局中手写的单位文字需自行修改**。导航距离仍为公里，燃油量仍为升。

打开“布局编辑器…”编辑当前方案，或点击“新建”创建“我的布局XX”。

- 将彩色信息控件拖入格子，点击格子直接键入单位、空格及符号。
- Shift 拖动框选，Ctrl 点击增减选择，拖动已选内容可整体移动；Delete 删除，Ctrl+Z/Y 撤销/重做。
- 命名后“保存并应用”，即可从主界面和编辑器的下拉框切换。修改默认布局会另存副本。
- “导出…”分享 JSON 文件，“导入…”可多选；“布局文件夹”可打开 `data/layouts/` 批量复制、备份或分享。

控件包括车速、限速、挡位、油量、转速、游戏/现实时间、巡航目标、任务剩余、导航用时/距离、休息倒计时和燃油升数。自定义布局油量最高显示99，两套默认布局保留100%。时长不超过24小时显示 `HH:MM`，超过后显示如 `2d11h`，10天以上显示如 `010d+`。空间不足时用滚轮浏览编辑器，Shift+滚轮横向浏览。

## 在线更新

点击主界面“检查更新…”，可查看新版和更新说明、下载更新包或取消下载，也可勾选启动时自动检查并保存。下载在后台进行，不影响仪表同步；完成后会校验 SHA256 和 ZIP 完整性，点击“打开下载目录”即可找到文件。

首次使用需填写发布者提供的 HTTPS 更新源地址；未配置时会明确提示。下载文件位于 `data/updates/`。解压到新目录后，关闭旧版并复制整个 `data/` 文件夹，以保留布局、设置和更新源。程序不会自动替换正在运行的文件。

## 兼容性与常见问题

- 支持欧卡2和美卡的64位游戏，自动识别遥测来源；切换时先退出上一款游戏。
- 本程序只读共享内存获取遥测，不监听遥测网络端口。同一兼容遥测插件可供多个读取程序共用，但其他 SDK 插件仍可能发生版本或共享内存冲突。**SimHub 等软件尚未联合实测，不能保证所有组合兼容**；[SimHub 官方说明](https://github.com/SHWotever/SimHub/wiki/SimHub-Basics----Games-config-and-troubleshooting#ets2--ats)也提示部分遥测插件分支存在冲突。
- 安装器保留其他插件，拒绝覆盖不同版本的同名插件。遇到冲突请先保留原文件、核对双方插件要求，不要直接删除、改名或替换其他仪表所需的插件。本程序使用附带的 V.1.12.1 插件（共享内存修订12）。
- 一直等待游戏：确认插件安装到了正在运行的游戏目录，重启游戏并进入驾驶。音响不更新：检查 USB 数据连接及是否有其他程序控制屏幕。

设置、布局和日志保存在程序旁的 `data/`。升级或迁移前关闭旧版，将整个 `data` 文件夹复制到新版程序旁即可保留配置。反馈问题时可提供 `data/dashboard.log`。组件许可见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。
