# 在线更新发布方法

程序端已支持稳定版本检查、更新说明、后台下载、取消、SHA256和ZIP校验。发布地址尚未确定时不内置虚假地址；用户可在“检查更新…”中填写真实地址。启动自动检查默认关闭，手动检查可随时使用。应用不会收集或上传遥测、游戏路径、布局和设置；更新请求仅发送HTTP请求及应用版本User-Agent。

## GitHub Releases

1. 在自己的仓库创建对应版本的 Release，例如 `v0.5.0`。
2. 将构建输出 `dist/HaloTruckDash-v0.5.0.zip` 和 `dist/latest.json` 作为**同一个 Release 的附件**上传，并发布为最新稳定版。
3. 更新源填写 `https://github.com/所有者/仓库/releases/latest/download/latest.json`（将所有者和仓库换成真实值）。不填写仓库首页或普通Release网页。

清单中的下载URL默认为相对ZIP文件名；客户端会按清单版本固定到 `v版本号` 标签的GitHub附件地址，兼容GitHub最后跳转到签名CDN的情况。默认发布标签需使用 `v0.5.0` 这类格式；使用其他标签且从latest入口检查时，请通过下述 `--download-url` 指定绝对附件地址。

## 自建HTTPS网站

面向国内用户，建议先用阿里云OSS国内地域（已有腾讯云账号也可用COS）。使用存储桶默认HTTPS域名即可作为更新源，初期无需另购服务器或配置CDN。

1. 准备标准存储桶及更新文件目录，开放更新清单和ZIP的公开读取，写入保持私有。程序只访问文件网址，不需要任何云账号密钥。
2. 上传ZIP，再上传 `latest.json`，两者位于同一目录；清单地址填写到程序的“检查更新…”中。使用可长期读取的HTTPS地址，不使用短期有效的签名链接。
3. 建议清单设置 `Cache-Control: no-cache`，ZIP按版本保留独立文件名。用户增多后再评估CDN。
4. 对象存储有存储、请求、外网下载流量等费用，设置费用提醒，具体以所选地域和控制台报价为准。

阿里云默认HTTPS域名说明：https://help.aliyun.com/zh/oss/user-guide/access-and-network-overview

阿里云流量计费说明：https://help.aliyun.com/zh/oss/traffic-fees

将 `latest.json` 与对应 ZIP 放在同一个公开HTTPS目录，在客户端填写 `latest.json` 的完整地址。先上传新版本ZIP，最后替换清单，避免清单已更新但文件未就绪。也可以生成指定绝对下载地址的清单：

```powershell
.\.venv\Scripts\python.exe tools/make_update_manifest.py --archive dist/HaloTruckDash-v0.5.0.zip --output dist/latest.json --download-url https://你的域名/更新包.zip --notes "本次更新说明"
```

真实地址需URL编码；不要把示例地址直接填入程序。HTTPS证书需有效，下载地址或重定向不能降为HTTP。无需额外的后台API、账号登录或数据库。

## 后续构建

修改 `halo_dashboard/version.py` 中的 `VERSION` 后运行 `build.ps1`。脚本同步生成版本目录、ZIP及校验值和字节大小匹配的清单；**不要在生成清单后再修改ZIP**。已确定固定更新源时，可将其写入同文件的 `DEFAULT_UPDATE_URL`，后续用户无需手动配置。已有用户保存的更新源仍优先使用。

更新包不含用户data目录。下载只是下载及校验，不自动执行或覆盖程序、用户布局或游戏插件。保留完整data目录即可迁移用户配置。

参考GitHub官方附件固定链接说明：https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases
